# 郷愁

> 味覚は郷愁のなかで最も頑固な記憶です――家から遠ざかるほど、あの糁飯（サンファン）の一碗はより香しく感じられます。

靖遠と平川は黄河の上流、シルクロードの肥沃な土地にあります。靖遠は古くから<strong>「塞上の江南」</strong>、「隴上の名邑」、「黄河の真珠」と称えられてきました。黄河は県内を154キロメートル流れ、甘粛省内のどの県よりも長い流路を持ちます。豊かな水と土が、独自の食文化を育んできました。

## 硬菜（インツァイ）三絶

靖遠は<strong>「羊羔肉のふるさと」</strong>であり、甘粛省最大の子羊肉の産地・集散地です。地元の食は小麦粉の主食を中心に雑穀を組み合わせ、味付けは濃いめ、量はたっぷり。そのなかでも三つの「硬菜」は隴原一帯に名を轟かせています：

### 🐑 靖遠羊羔肉

「名は塞北に轟き、誉れは隴原に満ちる」。靖遠の羊羔肉は、哺乳類として中国で初めて登録された**国家地理標志商標**です。筋繊維は細かく、柔らかさはきわめて高く、臭味はほとんどなく、香りは豊かです。爆炒め、紅焼き、黄燜、乾炸、焼き物、清燉、蒸し物など、10種類以上の漢方生薬を薬味にして作られ、どの調理法も一級品です。

### 🐴 東湾驢肉

東湾鎮の看板料理。色鮮やかで味わい深く、<strong>「一泡二焯三慢煮」</strong>（まず浸し、次に湯通しし、最後にじっくり煮る）という作法を守って作られます。独特の風味があり、靖遠を訪れる人なら必ず味わいたい一品です。

### 🥘 酸爛肉

別名「酸菜と春雨の豚肉炒め」。もとは農家の日常のおかずでした。漬けた白菜を細切りにし、ジャガイモ澱粉の春雨、豚肉と一緒に強火で炒めます。酸味の効いた香りが広がり、安価でおいしい料理です。黄米の糁飯を一碗添えれば、最も地元らしい故郷の味になります。今では農家の竈から晴れの席へと進み、来客をもてなす一品となりました――そして、靖遠・平川の出身者が故郷を離れてから最も恋しがる味でもあります。

## 主食と家庭の味

| 分類 | 代表例 |
|------|------|
| **蒸し物** | 蒸し饅頭、花巻、馬蹄子（マティズ）、月餅、包子（パオズ）、発糕、黄米の甘い饃饃 |
| **煮物** | 長面（臊子麺）、截截子、旗花子、麺片、餃子、**糁飯（サンファン）**、蕎麦の攪団（ジャオトゥアン） |
| **焼き物** | 鍋盔（外はさくっと、中はふんわり、保存しやすい）、大餅、**一窩糸（細さは髪のごとく、香ばしい）** |
| **揚げ物** | 油餅、油条、麻花（揚げねじりパン）、酥合子、糖油糕 |
| **冷たい麺** | 釀皮（リャンピー）――西北地方の定番冷菜。つるりとしてこしがあり、夏の暑さを癒やす一品 |
| **飲み物** | 罐罐茶、**漿水（発酵させたセロリの水、暑気を払い解毒する）**、醪糟、甜酒醅、麦茶、棗茶 |

### 季節の山菜

春から夏にかけて、苦苣菜（ニガナ）、野韭、野葱、苜蓿、地軟軟（イシクラゲ）、枸杞の芽、榆銭（ニレの実）、槐花などが次々と登場します。これは自然がこの土地に与えた贈り物です。

### 宴席と年中行事

- **婚礼**：<strong>「十三花」</strong>の宴が定番で、13品の炒め物が順に運ばれ、吉祥と円満を象徴します
- **節句や祝い事**：花饃饃（飾り蒸しパン）はターメリック、フェヌグリーク、紅麹で色を付け、菊や蓮、仏手柑の形に整えます。「点心」とも呼ばれ、親戚や友人を訪ねるときの体裁のよい手土産になります

## 七つの地理的表示

靖遠は**7つの国家地理的表示保護産品**を有し、**全国初の農産物品質安全県**の一つに選ばれています：

> 🏅 小口棗（ナツメ）・靖遠枸杞（クコ）・靖遠黒瓜籽（黒スイカの種）・靖遠羊羔肉・靖遠文冠果油（文冠果の油）・靖遠旱砂西瓜・大廟香水梨（香梨）

また「中国文冠果の郷」「隴原野菜の郷」「枸杞の郷」「籽瓜の郷」などの称号も持っています。
