# 私について

## 故郷：平川

私は**甘粛省白銀市平川区**の出身です。かつて靖遠に属していた、鉱山で栄えた小さな町です。

![平川の街並み](https://www.bypc.gov.cn/upfiles/cms/20210417/1606112264194120.jpg)

### 地名の由来

平川は甘粛省中部、黄河の上流に位置し、靖遠県の中央部に楔のように食い込んでいます。その名は区域内に広がる**10万畝（約6,700ヘクタール）の乾いた平らな河原**に由来します。総面積は約2,009平方キロメートル、常住人口は約19万人、4つの街道、5つの鎮、2つの郷を管轄し、区政府は興平路街道に置かれています。気候は典型的な温帯大陸性乾燥気候で、年平均気温は10.6℃、年間降水量はわずか195ミリです。

### 歴史の歩み

平川は**シルクロード**上の重要な宿駅でした。その歴史は秦の時代にまでさかのぼります：

| 時代 | 主な出来事 |
|------|--------|
| **秦** | 始皇帝33年（紀元前214年）、蒙恬が黄河以南の地を回復し、**鹯陰城**を築城。北地郡に所属 |
| **前漢** | 元鼎3年（紀元前114年）、**鹯陰県**を設置。現在の白銀市域で最も早い県級の行政区画。鹯陰口はシルクロードで最も早く重要な黄河の渡し場の一つ |
| **西魏** | 平涼郡を**会州**と改称。鹯陰は州治と郡治を兼ね、地域の政治・経済・文化の中心へと発展 |
| **明** | 正統2年（1437年）、靖虜衛を設置し、**迭烈遜巡検司**を置く |
| **清** | 同治12年（1873年）、左宗棠が**打拉池分県**の設置を奏上 |
| **現代** | 1985年5月14日、国務院が白銀市の地級市としての復置を認可。靖遠県から宝積鎮と5つの郷を分割し、**平川区が正式に発足** |

### 鉱山と工業の町

平川は典型的な資源型都市です。石炭の確認埋蔵量は**11億3,700万トン**、陶土の埋蔵量は**40億トン**を超えます。石炭、電力、陶磁器が三大基幹産業で、**「西部の陶都」**と呼ばれてきました。銀川―蘭州高速鉄道、京蔵高速道路、国道109号線が区域内を通っており、交通は便利です。

### 赤い記憶

- **1932年**：水泉起義――甘粛省内で共産党が指導した最初の武装蜂起
- **1936年10月**：紅軍第一・第四方面軍が**打拉池で会師**し、現在の白銀市域で最も早い農会革命政権の一つを樹立

### 名所と文化

区域内には陶磁器の町（国家3A級観光景区）、黄河岩画、秦漢の鹯陰城遺跡、王進宝将軍の墓、北武当、小黄湾の古い村落などがあります。
